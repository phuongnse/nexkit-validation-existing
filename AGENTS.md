# Project instructions

- Use English for source, comments, documentation and GitHub artifacts.
- Preserve the documented HTTP contract unless an approved requirement changes it.
- Use Python's standard library and unittest; this service has no dependencies.
- Keep unit and HTTP tests independently runnable using the README commands.
- HTTP verification must exercise the real service process and response body.
- Keep the default listener on loopback and use temporary ports in tests.
- Update the README when observable behavior or commands change.
